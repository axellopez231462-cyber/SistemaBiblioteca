# Módulo Frontend — BiblioTech

## Tecnologías Utilizadas
- **HTML5 Semántico**
- **Tailwind CSS v3 (vía CDN):** Estilos responsivos
- **FontAwesome v6:** Iconografía
- **JavaScript ES6+ (Vanilla):** Lógica reactiva en memoria (SPA)

## Módulos Desarrollados
1. **Inicio / Dashboard:** Indicadores KPI en tiempo real (Libros, Prestados, Lectores, Vencidos).
2. **Catálogo de Libros:** Filtro por categoría, buscador en vivo y alta de ejemplares.
3. **Lectores:** Control de usuarios y estados ("Activo" / "Suspendido").
4. **Préstamos y Devoluciones:** Emisión de préstamos y ajuste automático de stock al devolver.
