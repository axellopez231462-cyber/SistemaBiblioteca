*Sistema de Gestión Bibliotecaria

Solución informática web desarrollada para automatizar la administración del catálogo de libros, registro de lectores y control dinámico de préstamos y devoluciones.

*Estructura del Repositorio
-`/Frontend`: Interfaz web interactiva en JavaScript ES6+ y Tailwind CSS.
-`/Backend`: Propuesta de arquitectura API RESTful.
 -`/BD`: Modelo relacional de base de datos.
